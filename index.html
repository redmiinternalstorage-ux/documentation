🎯 Project Overview

What is Learning Curve LMS?

A full-stack, role-based education management platform built as an iMCA final-year project at LJ University.

📖
Course Management
Instructors create and manage rich course content. Students enroll, track progress, and access learning materials all in one place.
🤖
AI Chatbot Support
An integrated AI assistant helps students with queries, provides instant support, and reduces instructor workload.
📜
Certificate Generation
Automated PDF certificate generation via DomPDF upon course completion — downloadable and verifiable.
📊
Attendance Tracking
Real-time attendance recording with analytics dashboards for instructors and administrators.
💰
Finance Management
Salary payments, fee tracking, and financial reporting — all managed by the Finance Manager role.
📧
SMTP Mail System
Automated email notifications for enrollments, deadlines, results, and system events via SMTP integration.

🔄 Development Process

Agile Sprint Methodology

Iterative development with clear milestones, version control, and PSR-12 compliance throughout.

Sprint 1 — Project Setup & Auth
Laravel project scaffolding, database design, authentication system, role-based middleware, and base UI with Tailwind CSS.
Sprint 2 — Core Modules
Course creation, enrollment flow, instructor dashboard, student portal, and material upload functionality.
Sprint 3 — Tasks, Submissions & Grading
Assignment creation, student submission workflow, instructor grading interface, and automated feedback system.
Sprint 4 — Advanced Features
AI Chatbot integration, PDF certificate generation via DomPDF, SMTP mail notifications, and attendance tracking.
Sprint 5 — Finance & Admin
Finance Manager module, salary payment tracking, fee management, administrator analytics, and system settings.
Sprint 6 — Testing & Refinement
Comprehensive UAT, bug fixes, performance tuning, security hardening, and final documentation preparation.
